# Free Mode

Obsidian Campus is designed to run **completely free on your own Mac**. This
file spells out exactly what that means.

## What is free — everything in the current version

| Part | Cost | Notes |
| --- | --- | --- |
| The visual campus | **Free** | Runs locally on your Mac. No hosting, no server, no account. |
| Tauri (desktop shell) | **Free** | Open source (MIT/Apache-2.0). |
| React (interface) | **Free** | Open source (MIT). |
| TypeScript | **Free** | Open source (Apache-2.0). |
| PixiJS (campus renderer) | **Free** | Open source (MIT). |
| SQLite (local database) | **Free** | Public domain. Your data lives in one local file. |
| Local files & storage | **Free** | Everything stays on your Mac, in your user folder. |
| Simulated agents | **Free** | The agents you see are driven by a local simulation — no AI service is called, ever. |
| All icons and artwork | **Free** | Generated by the project's own code at build/run time. No stock assets, no external image URLs, nothing licensed. |

**No hosting is required.** The app is not a website. Nothing is deployed
anywhere.

**No Mac App Store publishing is required.** You build the app yourself and
drag it into Applications. No Apple Developer membership ($99/yr) is needed
for your own private use — that only becomes relevant if you later want to
distribute the app to other people (signing/notarisation).

## What could cost money later — all optional, all off

Paid AI providers (such as the Anthropic/Claude API or OpenAI) are **optional
and disabled by default**. The current version:

- ships with **Offline Simulation** selected as the AI provider,
- never requests an API key,
- never creates an account,
- never enables billing or automatic credit reloads,
- has no code path that calls a paid service.

The **Settings → AI Provider** section stores a *preference* for later phases
(Local Model, Ollama, Custom Provider). Selecting one today changes nothing —
the campus keeps running the free simulation, and the settings panel says so.
When real provider connections are added, anything that can create charges
will warn you explicitly before it is enabled, and API keys will be stored in
the **macOS Keychain** — never in source code, configuration files, Git, or
logs.

## Local AI models — free, but hardware-hungry

A later phase can connect **Ollama** or another local model runtime. Local
models are free to run (no API charges), but be aware:

- Useful models need **8–64 GB of RAM** depending on size.
- Model files occupy **4–40+ GB of disk** each.
- Generation speed depends heavily on your Mac's chip; Apple Silicon with
  plenty of unified memory works best.

Nothing about the current version requires this. It is a future option, not a
dependency.

## Where your data lives

Everything the app saves is local:

```
~/Library/Application Support/com.obsidiancampus.app/campus.sqlite
```

The app keeps the **last 20 revisions** of your campus inside that database
automatically (its built-in backups), and you can export/import your whole
campus as a portable JSON file from **Settings → Data**.

## The one cost that exists

Your electricity. That's it.
